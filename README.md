
# Agenda Deportiva

Aplicación web desarrollada para consultar encuentros deportivos utilizando una API REST de SportScore.

# Funcionalidad

- Filtro por deporte.
- Filtro por competiciones.
- Filtro por fecha.
- Visualización de encuentros y resultados.
- Visualización de goles y amonestaciones en partidos de fútbol finalizados.
- Identificación de goles de penal.
- Consulta de fútbol, baloncesto y tenis.

# Tecnologías utilizadas

- HTML.
- CSS. 
- JavaScript.
- Bootstrap.
- API REST SportScore.

# Deportes disponibles

- Fútbol.
- Baloncesto.
- Tenis.
